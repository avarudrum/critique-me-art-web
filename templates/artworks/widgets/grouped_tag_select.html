{% comment %} Template for GroupedTagSelect. One collapsible category per block -- Medium, Technique, Subject -- each holding its chips, with the least-used tags still tucked into the inner "N more" disclosure once a category passes the threshold. Collapsing the categories keeps the upload form short, but it also hides what you have ticked, which matters here in a way it does not on the browse filters: picking tags *is* the task on this page, and at least one medium is required. So the closed toggle always names its own selection. Nothing is hidden from the form itself -- every checkbox stays in the DOM, collapsed or not, so it submits either way. The shared `name` makes the categories exclusive. Without it, opening a second category would drop its floating panel on top of the one already open. {% endcomment %}
